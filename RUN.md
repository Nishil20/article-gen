# Run Commands

## Install dependencies
```bash
npm install
```

## Run all apps (dashboard + landing)
```bash
npm run dev
```

## Run only dashboard
```bash
cd apps/dashboard && npm run dev
```
- Runs on: http://localhost:3001

## Run only landing
```bash
cd apps/landing && npm run dev
```
- Runs on: http://localhost:3000

## Build
```bash
npm run build
```

## Lint
```bash
npm run lint
```
