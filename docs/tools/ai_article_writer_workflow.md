# AI Article Writer — Screen-by-Screen Workflow

## Screen 1 — New Article Form
- Title  
- Primary keyword  
- Secondary keywords  
- Tone (dropdown)  
- Target word count  
- Audience (dropdown)  
- Competitor URL (optional)  
- **Button:** Next → Generate Outline

---

## Screen 2 — Outline Editor
- Show generated outline as editable list  
- Allow drag/drop, add, delete headings  
- **Button:** Regenerate Outline  
- **Button:** Next → Generate Draft

---

## Screen 3 — Section Draft Generator
- For each heading:  
  - Generate Section button  
  - Rewrite / Regenerate / Expand options  
- **Button:** Generate All Sections  
- **Button:** Next → Full Editor

---

## Screen 4 — Full Article Editor
- Rich text editor with entire article  
- Light rewrite tools  
- **Button:** Next → SEO Optimization

---

## Screen 5 — SEO & Meta Details
- SEO title  
- Meta description  
- Slug  
- Keyword coverage checklist  
- Readability score  
- **Button:** Finish → Export

---

## Screen 6 — Export / Publish
- Export as HTML  
- Export as Markdown  
- Copy to clipboard
